# 每週爆谷評價（GitHub Pages）

Live: https://axelau.github.io/weekly-popcorn/

## Structure

```
index.html           # archive homepage (year → month → week)
YYYY-MM-DD/
  index.html         # that week's digest
  assets/            # local cover images (relative paths)
```

- Root `index.html` is **only** the archive hub.
- Each week lives under its own dated path and is **not** overwritten when a new week ships.
- Week pages keep `assets/…` relative to their own folder.
